# Reference Books

This page contains recommended textbooks and reference materials for the Natural Language Processing course.

---

## Speech and Language Processing

**Authors:**

Daniel Jurafsky and James H. Martin

**Official Book Website:**

https://web.stanford.edu/~jurafsky/slp3/

### Recommended Chapters

- Chapter 1: Introduction
- Chapter 3: Regular Expressions and Text Processing
- Chapter 6: Language Modeling
- Chapter 10: Transformers
- Chapter 11: BERT and Transfer Learning

### Notes

This is one of the most widely used textbooks in Natural Language Processing and serves as a primary reference throughout this course.

---

## Natural Language Processing with Python (NLTK Book)

**Authors:**

Steven Bird, Ewan Klein, and Edward Loper

**Official Book Website:**

https://www.nltk.org/book/

### Recommended Chapters

- Chapter 1: Language Processing and Python
- Chapter 3: Processing Raw Text
- Chapter 4: Writing Structured Programs

### Notes

Excellent resource for Python programming and text processing tasks in NLP.
