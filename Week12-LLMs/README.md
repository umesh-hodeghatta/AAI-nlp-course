## Topics Covered

- Introduction to Large Language Models
- Foundation Models
- Generative AI
- Prompt Engineering
- Zero-Shot Learning
- One-Shot Learning
- Few-Shot Learning
- Retrieval-Augmented Generation (RAG)
- LLM Applications
- Responsible AI Considerations

## Learning Objectives

By the end of this week, students will be able to:

- Explain the architecture and capabilities of Large Language Models
- Understand how foundation models are trained and used
- Apply prompt engineering techniques
- Compare zero-shot, one-shot, and few-shot prompting
- Describe Retrieval-Augmented Generation (RAG)
- Evaluate opportunities and limitations of LLM-based systems
